# Preditor de Falhas em Rede – Grupo 7
 
Projeto interdisciplinar que usa medições públicas de ping do **RIPE Atlas** para classificar cada fluxo de rede em **OK**, **RISCO** ou **FALHA** e prever a classe da próxima medição.
